# ASOAGROTURÍ Landing Page

Landing page de prueba desarrollada para **ASOAGROTURÍ**, una asociación orientada al desarrollo rural, el fortalecimiento del sector agropecuario y la promoción del turismo rural.

El proyecto busca presentar la identidad de la asociación, comunicar su propósito y ofrecer una experiencia digital clara, moderna y adaptable a diferentes dispositivos.

## Descripción del proyecto

Esta landing page constituye una propuesta inicial de diseño y desarrollo web para ASOAGROTURÍ.

Su objetivo es organizar y presentar información institucional mediante una interfaz intuitiva, visualmente atractiva y responsive.

**Estado:** Proyecto de prueba / prototipo web.

## Tecnologías utilizadas

- Angular 22
- TypeScript
- HTML5
- CSS3
- Angular CLI

## Características

- Diseño responsive para dispositivos móviles, tablets y escritorio.
- Estructura modular mediante componentes de Angular.
- Secciones informativas sobre la asociación.
- Navegación entre las diferentes secciones de la landing.
- Identidad visual basada en los elementos gráficos de ASOAGROTURÍ.

## Requisitos

Para ejecutar el proyecto localmente necesitas:

- Node.js
- npm
- Angular CLI

## Instalación y ejecución

Clona el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Ingresa a la carpeta del proyecto:

```bash
cd asoagroturi-landing
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
ng serve
```

Abre en el navegador:

```text
http://localhost:4200/
```

## Compilación para producción

Para generar la versión optimizada del proyecto:

```bash
ng build
```

Los archivos compilados se encontrarán en la carpeta `dist/`.

## Estructura del proyecto

La aplicación utiliza la estructura de proyectos de Angular CLI y organiza su interfaz mediante componentes reutilizables.
